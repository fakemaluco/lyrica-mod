## Novidades do Lyrica 0.9.4

- Suporte a **Minecraft 26.3** com Fabric. Os JARs para 1.21.1, 1.21.11 e 26.2 também foram atualizados.
- O pop-up de karaokê ganhou uma aba lateral animada para consultar a fila do Spotify do anfitrião, pesquisar e enfileirar músicas e avançar até uma faixa. A fila usa a conta Spotify conectada ao Lyrica.
- A extensão do Spicetify foi descontinuada. As conexões do Spotify usam a conta Spotify ou a detecção de mídia do Windows.
- As letras 3D têm saída animada, incluindo queda e fade dos vocais de fundo. O cursor do karaokê acompanha o estado da interface ao usar F1.
- A distância das letras 3D tem mínimo e máximo no mesmo controle. A cor do texto cantado aceita cor sólida ou gradiente com vários pontos, aplicado à frase inteira por padrão.

Instale o JAR da sua versão do Minecraft junto com o Fabric API correspondente. Minecraft 26.2 e 26.3 usam Java 25. Cada JAR desta release inclui o **bridge nativo para Windows x64**.

## What’s new in Lyrica 0.9.4

- Added Minecraft 26.3 support and updated the 1.21.1, 1.21.11, and 26.2 builds.
- The karaoke panel’s animated side tab lets you browse the host’s Spotify queue, search and add tracks, and advance to a queued track.
- Retired the Spicetify extension. Lyrica uses the Spotify account connection or Windows media detection.
- World lyrics gained exit animations, including falling, fading backing vocals, and a two-handle distance control. The karaoke cursor follows the HUD visibility setting.
- Sung text supports a solid color and editable gradient stops. The gradient covers the whole phrase by default, with a per-word option.

Choose the JAR for your Minecraft version and install the matching Fabric API. Minecraft 26.2 and 26.3 use Java 25. Each release JAR includes the **Windows x64 media bridge**.
