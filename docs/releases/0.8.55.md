# Lyrica 0.8.55

- A romanização mantém os tempos de cada palavra e sílaba fornecidos pela fonte. A leitura de TTML associa os trechos romanizados aos originais, incluindo metadados Apple/AMLL e romanização dentro de cada palavra.
- A conversão do Spicy preserva espaços entre palavras e mantém os vocais de fundo separados. Metadados antigos do cache que omitiram espaços são reparados a partir das palavras originais.
- Uma alternativa de linha inteira não substitui nem junta palavras romanizadas que já têm sincronização. Palavras japonesas e chinesas sincronizadas separadamente continuam separadas ao usar a romanização local.
- Espaços antes ou depois de uma palavra deixam de apagar a romanização fornecida e de acionar o fallback local indevidamente.

Validação: testes do caminho JSON do Spicy → TTML → protocolo → texto do pop-up, com tempos não uniformes e pausas entre sílabas; regressões para espaços, escrita alternativa da linha, romanização local, metadados inline e vozes de fundo simultâneas. Compilação e suítes de testes concluídas para Minecraft 1.21.1, 1.21.11 e 26.2.

Quando a fonte oferece somente uma linha romanizada, sem tempos próprios, a correspondência com as palavras originais continua sendo uma aproximação. A correção preserva os tempos reais sempre que esses dados existem.
