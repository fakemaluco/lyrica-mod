# Extensão Spicetify descontinuada

A integração foi removida do Lyrica. Use **Conexões → Spotify** para conectar
sua conta pela API oficial. Se você instalou a extensão antiga, remova
`fandroid.js` da lista de extensões da sua configuração do Spicetify e aplique
a configuração novamente.

Veja o [guia de conexão](../../docs/GUIDE.md).
