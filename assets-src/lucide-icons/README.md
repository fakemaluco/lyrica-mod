Official SVG assets from [Lucide](https://github.com/lucide-icons/lucide/tree/main/icons), under the included ISC license. No network request occurs in the mod.

Rebuild the 192px exports with `uv run --with resvg-py python scripts/export-lucide-icons.py`. Settings rasterize the bundled exports at the current framebuffer density; popup controls share the same source icons.
