# Popup icon sources

The Spicy Lyrics SVGs in this directory came from the two icon ZIPs supplied
for the popup. The game bundles 192 × 192 transparent PNG exports in
`mod/src/main/resources/assets/lyrica/textures/gui/lyrics/icons`.

`heart-outline.png` is the supplied heart with its `SpicyLyrics_HeartFill`
group omitted. `pause.svg` is a small matching control drawn for Lyrica because
the supplied set did not contain a pause icon. `close` and `lyrics-manager` are
retained as source exports, although the current popup has no matching controls.
