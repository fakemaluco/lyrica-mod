# Bundled silent video runtime

Lyrica uses JavaCV 1.5.11 and JavaCPP 1.5.11, Copyright Samuel Audet and
contributors, under their Apache License 2.0 option. FFmpeg's JavaCPP bindings
come from JavaCPP Presets 1.5.11 under Apache License 2.0. Complete license
texts are in `licenses/video/` and included in this module's JAR.

The standard (non-`gpl` classifier) FFmpeg 7.1 native build is bundled for the
release build's target platform. The Bytedeco build enables `--enable-version3`,
so FFmpeg is used under LGPL version 3 or later; the LGPLv3 and its incorporated
GPLv3 text are included alongside the LGPLv2.1 text from FFmpeg's source.
The libraries remain shared native libraries, extracted by JavaCPP's loader;
they are not statically linked into Minecraft or Lyrica.

Matching source and build instructions:

- JavaCV: <https://github.com/bytedeco/javacv/tree/1.5.11>
- JavaCPP: <https://github.com/bytedeco/javacpp/tree/1.5.11>
- Native bindings, dependency versions and build recipes:
  <https://github.com/bytedeco/javacpp-presets/tree/1.5.11/ffmpeg>
- FFmpeg 7.1 source: <https://ffmpeg.org/releases/ffmpeg-7.1.tar.xz>

The native build recipe lists its codec/TLS/font dependencies and the source
download URLs for each one. No media files are bundled with production Lyrica.
The deterministic MPEG-4 development fixture is generated by Lyrica's tests.

Release builds target the host platform by default. Override `-PvideoPlatform`
with a JavaCPP classifier, for example `windows-x86_64`, `linux-x86_64`,
`linux-arm64`, `macosx-x86_64`, or `macosx-arm64`, when cross-packaging a release.
If native decoding is unavailable on the device, the static cover remains.
